Get started with Beetle

Load any of the 330 released checkpoints with from_pretrained, use the bilingual tokenizers, and reproduce the reading-time, grammaticality and structural-priming analyses from the paper.

Quickstart

Load a Beetle model in minutes

1 · Set up

bash
$ pip install transformers torch

Every released model and tokenizer is standard HuggingFace — no bespoke framework required. The 330 checkpoints span five curricula (B1–B5), three data scales (100M / 2B / 24B) and 21 first languages.

2 · Load a released checkpoint

python
from transformers import AutoModelForCausalLM, AutoTokenizer

name = "Beetle-HumanScale/beetle-bilingual-nl-en-b2"
model = AutoModelForCausalLM.from_pretrained(name)
tok   = AutoTokenizer.from_pretrained(name)

# score a sentence under the model
out = model(**tok("the beetle reads the sentence", return_tensors="pt"))
print(out.logits.shape)

Browse every checkpoint by language, curriculum and scale on the Models & Data page.

Guides

Step by step

From loading a released checkpoint to reproducing the paper’s evaluations.

1 · Load a model

Every Beetle checkpoint is standard HuggingFace — load it with from_pretrained.

from transformers import AutoModelForCausalLM
m = AutoModelForCausalLM.from_pretrained(
  "Beetle-HumanScale/beetle-monolingual-humanscale-eng")

2 · Use a beetle tokenizer

Bilingual and human-scale BPE tokenizers are published on the Hub and load the same way.

from transformers import AutoTokenizer
tok = AutoTokenizer.from_pretrained(
  "Beetle-Data/tokenizer-nl-en")
print(tok("Hello, beetle!"))

3 · Pick a curriculum & scale

Checkpoints are named by first language, curriculum (B1–B5) and data scale (100M / 2B / 24B), so each experiment is directly comparable.

# B2 staged curriculum, Dutch L1, 24B tokens
AutoModelForCausalLM.from_pretrained(
  "Beetle-FineWeb/beetle-nl-en-b2-24b")

4 · Step through training

Dense intermediate checkpoints let you trace learning dynamics across training steps via the revision argument.

AutoModelForCausalLM.from_pretrained(
  "Beetle-FineWeb/beetle-nl-en-b2-24b",
  revision="step-8000")

5 · Run a minimal-pair eval

Score BLiMP-style and BLiSS learner minimal-pair discrimination on any loaded checkpoint.

from beetle_analyze import minimal_pair_accuracy
minimal_pair_accuracy(m, tok, dataset="BLiSS")

6 · Compare to human data

Align model surprisal with MECO L2 reading times and test cross-lingual structural priming — the paper’s core analyses.

from beetle_analyze import reading_time_fit
reading_time_fit(m, tok, corpus="MECO-L2")

Ecosystem

Four repositories, end to end

beetlelm

The core framework behind the released suite: the architecture zoo (PicoDecoder backbone), the modular tokenizer, the B1–B5 exposure curricula, and HuggingFace-compatible checkpoints.

Open repository

beetle-data

A minimal, reproducible bilingual data-preparation pipeline: build a corpus, train a BPE tokenizer, pretokenize into shards, and report stats — for small language models.

Open repository

beetle-analyze

A minimal, reproducible toolkit for analysing language-model evaluation output via BLiMP-style minimal-pair accuracy.

Open repository

beetle-explorer

Load and play with Beetle language models in Colab — no coding required. A non-technical companion to the beetlelm training framework.

Open repository
