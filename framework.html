Framework

The Beetle Framework

Change how a model learns. Discover what changes.

What happens when a language model learns two languages at once instead of one after the other? When does more training data help? How does tokenisation shape what a model learns? The Beetle framework lets you design controlled experiments to find out. Change how a model is trained, compare the results, and investigate how its behaviour and internal representations develop.

Controls

What can you experiment with?

Language exposure

Train models on different languages and compare when and how they encounter each one.

Training data

Compare models trained on different amounts of data, from smaller budgets to billions of tokens.

Tokenisation

Investigate how splitting text into units affects language learning and multilingual transfer.

Learning over time

Evaluate checkpoints throughout training to track how model behaviour changes.

Research questions

From research question to experiment

🌍 Compare language-learning strategies

Beetle provides five training curricula, B1 to B5, that vary how and when models encounter languages.

  • Does learning two languages simultaneously differ from learning them sequentially?
  • What happens when a model encounters a second language later in training?
  • How does language exposure affect what a model learns?

📈 Test the effects of training

Compare models across training budgets and learning trajectories.

  • Does more data improve performance?
  • Do different training strategies lead to different outcomes?
  • Do patterns in smaller models persist with more training?

🔤 Investigate tokenisation

Change how text is represented before it enters the model.

  • Does tokenisation affect grammatical learning?
  • Does it change how information transfers between languages?
  • Which effects can be attributed to tokenisation rather than other training choices?

🧠 Study how models develop

Use intermediate checkpoints to investigate learning as it happens.

  • When do particular capabilities emerge?
  • How do internal representations change during training?
  • Do different learning histories produce different outcomes?
Toolkit

Use the tools you need

Beetle is built from four small, open-source repositories. Use them together or adapt individual components for your own experiments.

beetlelm · Train models

The core training framework: model architectures, tokenisation options and B1 to B5 exposure curricula.

GitHub repository  ·  Tutorial

beetle-data · Prepare data

Build and process training corpora, train BPE tokenisers and prepare data for model training.

GitHub  ·  Tutorial

beetle-analyze · Evaluate models

Analyse model performance, minimal-pair evaluations, reading-time alignment and internal representations.

GitHub  ·  Tutorial

beetle-explorer · Try models in Colab

Explore existing models, choose languages and training conditions, select checkpoints and generate text without building your own training pipeline.

GitHub  ·  Tutorial
